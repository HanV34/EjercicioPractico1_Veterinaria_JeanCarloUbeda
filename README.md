# Clínica Veterinaria Kratos

Aplicación web (Spring Boot, JPA, Thymeleaf, MySQL) para gestionar tipos de servicio y servicios veterinarios, consultar citas y enviar consultas.

## Cómo ejecutarla
1. En MySQL Workbench abrir y ejecutar `script_veterinaria.sql` (crea la base `veterinaria_citas`, el usuario y los datos de prueba).
2. Abrir el proyecto en NetBeans y ejecutarlo (clase `VeterinariaApplication`).
3. Entrar a http://localhost:8086
